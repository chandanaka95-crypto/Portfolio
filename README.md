## 🌟 Overview

This is a modern, responsive, professional personal portfolio website crafted with pure **HTML5**, **CSS3 (Vanilla)**, and **JavaScript (Vanilla)**. It is specifically tailored for sharing with internship recruiters, featuring a navy blue, crisp white, and light blue aesthetic.

### ✨ Key Highlights & Features
- **Aesthetic Color Palette:** Built using curated Navy Blue (`#0a192f`), Royal Blue (`#2563eb`), vibrant Light Blue/Cyan (`#38bdf8`), and crisp white.
- **Dynamic Subtitle Typing Effect:** Cycles through professional titles like *"Aspiring Software Developer"*, *"ISE Student @ AMC College"*, *"Python & C Programmer"*.
- **Dark Navy / Crisp Light Theme Switcher:** Smooth transition with persistent preference saved in `localStorage`.
- **Responsive Portrait Frame:** Clean rounded portrait with glowing border, status badge (*"Open to Internships"*), and floating academic stat cards.
- **Interactive Resume Modal:** Quick one-click CV preview with built-in *"Print / Save as PDF"* styling.
- **Academic & Coursework Integrity:** Realistic project placeholders clearly structured for student projects (DBMS Portal, DSA Toolkit, Analytics) with direct instructions for updating links.
- **Interactive Contact Form & One-Click Copy:** Client-side validation with `mailto:` email generation and clipboard copy buttons.
- **100% Mobile & Desktop Responsive:** Optimized navigation with hamburger menu drawer and smooth scrolling.

## 🚀 How to Run Locally

### Option 1: Direct Browser Launch (Easiest)
1. Navigate to the project folder: `c:\Users\OM\OneDrive\Scans\Documents\Desktop\InAmigos`.
2. Double-click on `index.html` to open it directly in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Using VS Code Live Server (Recommended)
1. Open the `InAmigos` folder in **Visual Studio Code**.
2. If you have the **Live Server** extension installed:
   - Right-click `index.html` and click **"Open with Live Server"**.
3. The site will automatically launch at `http://127.0.0.1:5500/index.html`.

### Option 3: Using Python Built-in Server
Open PowerShell in the `InAmigos` folder and run:
```powershell
python -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.

## 🌐 Step-by-Step Guide to Publish Online (Free Live URL)

To submit Task 1 for the **InAmigos Foundation Internship**, you need a live public URL. Choose any of these 3 free hosting platforms:

### 🚀 Method 1: Netlify Drop (Fastest — 1 Minute, No Git Required)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop) (Sign up for a free account if you haven't already).
2. Drag and drop the entire `InAmigos` folder into the Netlify Drop area.
3. Within 10 seconds, Netlify will deploy your site and provide a live URL like:  
   `https://chandana-ka-portfolio.netlify.app`
4. You can click **Site configuration > Change site name** to give it a custom name like `chandana-portfolio.netlify.app`.

### 🐙 Method 2: GitHub Pages (Industry Standard for Developers)
1. Log in to [GitHub](https://github.com/) and create a new public repository named `portfolio` (or `chandanaka.github.io`).
2. Push your files from this folder to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Chandana K A portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. In about 1 to 2 minutes, your website will be live at:  
   `https://<your-username>.github.io/portfolio/`

### ▲ Method 3: Vercel
1. Visit [https://vercel.com/](https://vercel.com/) and log in with GitHub.
2. Click **Add New > Project** and select your GitHub repository.
3. Click **Deploy**. Your site will be live instantly with a free `.vercel.app` domain.
